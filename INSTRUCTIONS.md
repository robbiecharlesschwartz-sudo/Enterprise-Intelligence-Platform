# Instructions for Using GDI Enterprise Intelligence

This document explains how to use the GDI Enterprise Intelligence agent (RFP Evidence Responder) to complete RFP questionnaires in Microsoft 365 Copilot.

## 1. Starting a Session

Open the agent in Microsoft 365 Copilot and start a new chat, or select one of the suggested prompts shown in the agent's chat window.

## 2. Submitting an RFP

Paste or upload the incoming RFP questionnaire, then choose a prompt such as "Complete RFP" to complete the full questionnaire, or "Answer ESG Section" to complete only the ESG portion.

## 3. Reviewing Output

Fields with supporting evidence will be filled in using a first-person company voice (e.g., "We maintain..."). Fields without supporting evidence will be left blank - this is expected behavior, not an error. Use the "Review Blank Fields" prompt to get a summary of which fields were left blank and why.

## 4. Formatting and Finalizing

Use "Format Responses" to convert the answers into the RFP's requested table format. Use "Check Support" to have the agent re-verify that every claim is backed by evidence. Use "Create Final Output" to generate the final, submission-ready response in the original questionnaire structure.

## 5. Notes and Limitations

The agent will not ask for additional documents, clarification, or evidence - it only uses what is already connected through its knowledge sources. AI-generated content may be incorrect, so always review completed RFP responses before sending them to a customer or partner. This agent is intended for internal RFP-response drafting and should be reviewed by an authorized team member before external submission.
